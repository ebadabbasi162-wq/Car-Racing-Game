# Car Racing Game

A 2D Car Racing Game developed using **C# and Windows Forms** in Visual Studio. The game features player-controlled car movement, multiple enemy cars, road animation, score tracking, and collision detection.

## Features

- Player car movement using keyboard arrow keys.
- Multiple enemy cars with different movement speeds.
- Animated road lane markings.
- Real-time score tracking.
- Collision detection.
- Game Over functionality.
- Pause and Resume options.
- Restart functionality.

## Technologies Used

- C#
- .NET Windows Forms
- Visual Studio
- Git
- GitHub

## Controls

| Key | Action |
|---|---|
| Up Arrow | Move Up |
| Down Arrow | Move Down |
| Left Arrow | Move Left |
| Right Arrow | Move Right |
| Pause Button | Pause the Game |
| Resume Button | Resume the Game |
| Restart Button | Restart the Game |

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/ebadabbasi162-wq/Car-Racing-Game.git
   ```

2. Open the solution file in Visual Studio.
3. Build the project.
4. Run the application.
